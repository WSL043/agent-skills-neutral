# Implementation variants

## Structural operations

Use a PDF library for page operations, metadata, forms, extraction, encryption, and merging. Preserve untouched objects where fidelity matters.

## Designed generation

Generate from a content model and design tokens, then render every page. Separate content, layout, and final QA so reformatting does not corrupt source meaning.

## Visual verification

Rasterize the final output at a stable DPI and inspect representative, dense, and boundary pages. Structural success is not visual success.
