# Workflow modes

## New interface or visual polish

Read [design-quality.md](design-quality.md). Use it to turn the brief into one coherent design system and to catch repeated AI-default composition without replacing one rigid recipe with another.

## Existing-product redesign

Read [redesign.md](redesign.md). Audit first, classify preservation constraints, and separate visual modernization from approved structural change.

## Screenshot, mockup, or generated reference to code

Read [visual-reference.md](visual-reference.md). Treat the reference as evidence, extract its system, and compare rendered implementation against it.

## Platform style profile

Load a platform-specific reference only when the user explicitly requests that language. Treat it as a profile layered over the same hierarchy, state, accessibility, and verification rules.
